# Primary Contact Feature — Client Clarification Questions

**Context:** The client wants to add a "primary phone" and "primary email" marker per property, where different owners can hold the primary for each contact type (e.g. Jon is the primary phone contact, Lynda is the primary email contact).

---

## Questions for the client

### 1. What's the main reason for this feature?

What problem does it solve day-to-day? For example:

- **a)** Agents need a quick visual cue — "call Jon, email Lynda" — so they don't have to remember which owner to reach out to for what.
- **b)** Bulk actions (SMS blasts, automated reminders, mail-outs) should go to the primary contact's details, not always default to owner 1.
- **c)** Both — agents see the cue AND the system routes automated messages to the marked primary.

---

### 2. One primary per property, or a preference per owner?

When you say "primary phone" and "primary email" — do you mean:

- **a)** The property has one primary phone number (e.g. Jon's) and one primary email address (e.g. Lynda's), regardless of which owner they belong to.
- **b)** Each owner has a flag — "prefer phone" or "prefer email" — so Jon is the go-to for calls, Lynda for emails.

---

### 3. Visual only, or does it change what happens when you click call/email?

- **a)** Just a visual highlight (different colour, star, badge) so agents know at a glance — clicking any contact still works as today.
- **b)** The call/email quick-action buttons on the property list card should automatically use the primary contact's details instead of always defaulting to owner 1.

---

### 4. Is setting a primary required, or optional?

- **a)** Optional — only set it when needed; properties without a primary behave exactly as they do today.
- **b)** Required — every property must always have a designated primary phone and a designated primary email.

---

## Background (for context when answering)

Currently each property can have up to 3 owners. Each owner has one phone number and one email address stored against them. There is no "primary" flag today — the system just defaults to owner 1 whenever it needs to pick a contact.

The feature request is to let agents mark any owner's phone as the primary call number and any owner's email as the primary email address for that property — and these can be two different owners (as shown in the screenshot).
